# TikTok Downloader - starter project

## تشغيله على الكمبيوتر
1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   ```bash
   python -m venv .venv
   ```
   ثم فعّل البيئة الافتراضية:
   - Windows: `.venv\\Scripts\\activate`
   - macOS/Linux: `source .venv/bin/activate`
4. ثبّت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```
5. شغّل:
   ```bash
   python app.py
   ```
6. افتح `http://127.0.0.1:5000`

## النشر على الإنترنت
هذا مشروع بداية وليس موقعاً مستضافاً. للنشر تحتاج خدمة استضافة تدعم Python/Flask، وتضبط أمر التشغيل إلى `gunicorn app:app` (مع إضافة gunicorn إلى requirements)، وتراجع حدود التخزين والوقت وسياسة مزود الاستضافة.

## ملاحظات
- يعتمد تنزيل الفيديو على yt-dlp وقد تتغير آلية TikTok في أي وقت.
- لا يضمن المشروع إزالة العلامة المائية؛ يستخدم أفضل صيغة متاحة التي يستطيع المصدر توفيرها.
- استخدمه فقط للمقاطع التي تملكها أو لديك إذن بتنزيلها واستخدامها.
- قبل نشره للعامة، أضف تحديد معدل الطلبات، حدود حجم/مدة الفيديو، تنظيف الملفات المؤقتة، ومراقبة إساءة الاستخدام.
